# 幕墙折光 · 单时刻预览

可交互网页：选场景，拖倾角、日期、时刻和反射比，看这一时刻反射落在街面还是邻楼。全年 Gate 用已经跑完的扫描，本页不重跑。

本页不是经国家认可检测机构测试或 SJG 188「专业评估」的评价软件。

## 本地打开

在本目录起一个静态服务器：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8765/`。

核对预览几何和太阳位置：

```bash
node test_preview.mjs
```

`data/golden.json` 用 pvlib 的太阳向量。页面上的太阳位置是同一套几何公式，抽查与 pvlib SPA 相差约 0.4° 以内。着色用的直射是简化晴空，不是 TMY，也不是 Ineichen。

## 页面上有什么

- 场景：九龙 A、深南 B、开阔 C、伦敦凹面（Walkie-Talkie 验证场景）。几何来自 `../configs/`，板元步长 4 m，用来即时预览。全年扫描是 2 m。
- 倾角 α、日期、时刻、年、反射比 ρ。ρ 旁有 0.08 / 0.16 / 0.25 / 0.30 四档。
- 「连邻窗一起算」是现行几何口径：被照亮的反射要离开街面，并且不能进入邻楼盒子。「只护街」只计街面落点。
- 平面热力和南北剖面随滑条更新。Gate 旁注来自 `../results/*/gate_analysis.md` 和 `../STATUS.md`，开关不改那些全年数字。
- 窄屏按一列排，滑条拇指约 28 px，场景按钮可横滑。

## 只护街的抽样

`data/relax.json` 由 `precompute_relax.py` 生成。它调用上一层 `glare_sim`，不是浏览器里的预览公式。

抽样：4 m 板元，2026 年每月 15 日 8/10/12/14/16 时，pvlib Ineichen 且 DNI≥50，倾角 0–50° 每 2.5°。

九龙 A：现行口径无解 11,255 / 75,600（14.9%），其中 z≥20 m 为 9,497。只护街无解 0 / 75,600。被放松的 11,255 个都能在某个倾角离开街面，但没有任何倾角能导离邻楼。全年官方结论仍是无解，TMY 14,689,432 / 108,077,760。这段抽样不是新的全年 Gate。

深南 B 的抽样无解是 425 / 88,800，只护街为 0。全年仍是无解（TMY 658,606 / 127,320,000）。开阔 C 和伦敦凹面的抽样无解都是 0，与全年「没有无解板元时刻」同向；它们仍是仅动态可解，因为没有全楼统一角。

重跑抽样（需要上一层目录里的虚拟环境，会跑大约一两分钟，不会跑全年）：

```bash
../.venv/bin/python precompute_relax.py
```
